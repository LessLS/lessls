為什麼選擇 LessLS？

簡單、快速、強大 — 設計哲學驅動每一次操作

📦

簡易套件管理

使用 ls install 安裝任何套件，支援 LessLS Registry、npm 與 GitHub 倉庫。

🔐

多重登入方式

ls login 支援 GitHub OAuth、授權碼與 Token 三種模式，快速連上你的帳號。

🚀

一鍵發布

ls release 直接發布到 LessLS Registry，支援 Tag 與 Dry Run 模式。

⚡

GitHub 安裝

ls install github owner/repo 直接從 GitHub 倉庫安裝套件，無需額外配置。

🔄

自動更新

ls update 或 ls update github 從_registry_或 GitHub 更新至最新版本。

🔍

智能搜尋

ls search 快速搜尋 LessLS、npm 上的套件，支援關鍵字過濾。

完整指令列表

所有指令一覽，輕鬆上手

指令 說明 範例
ls install <pkg> 安裝套件到本地 ls install @lessls/lessls
ls install github <repo> 從 GitHub 倉庫安裝 ls install github lessls/lessls
ls login 取得授權碼，引導完成登入 ls login
ls login <code> 使用授權碼快速登入 ls login ABCD1234
ls login <user:token> 直接使用 Token 登入 ls login myuser:token123
ls release 發布當前專案 ls release --tag latest
ls update 從 Registry 更新 LessLS CLI ls update
ls update github 從 GitHub releases 更新 ls update github
ls search <kw> 搜尋套件 ls search http
ls list 列出已安裝套件 ls list
ls status 顯示 LessLS 狀態 ls status
ls help 顯示說明 ls help

快速安裝

三步驟開始使用 LessLS

1

安裝 Node.js

確保 Node.js 18+ 已安裝
如未安裝請前往 nodejs.org

node --version
# v18.0.0 或更高
2

全域安裝 CLI

透過 npm 安裝 LessLS 命令列

npm install -g @lessls/lessls
3

開始使用

登入並安裝第一個套件

ls login
ls install @lessls/weather
ls status
